Persistencia de datos:
Se debe aplicar localStoragepara almacenar, recuperar, borrar, modificar y vaciar datos del simulador. Esto es fundamental para la persistencia de datos y que no se pierdan selecciones del usuario.
Importante: Usa JSON.parse() - JSON.Stringify() para manipular array de objetos en el storage.
Renderizado dinámico:
El proyecto debe estar íntegramente planteado con el uso de DOM y Eventos, es fundamental para esta ultima parte del desarrollo del simulador.
Uso de Operadores Modernos:
Dentro de tu proyecto, intenta usar ? para reemplazar condicionales simples.
Destructuring:
Desestructurar un objeto al que le desees manipular propiedades, optimizando y modernizando el desarrollo de tu simulador.
