Modulo 7

Entregable

1. Preparación del Entorno
El repositorio debe contar con tres archivos: index.html, style.css y main.js, cada uno en su correspondiente carpeta, solo el index en la raíz.
En el HTML, prepara inputs para ingresar datos (ej: nombre de producto, precio) y un contenedores vacío (ej: <div id="contenedor-items"></div>) para renderizar estructuras dinámicas.
2. Modelado y Selección
En main.js, selecciona los elementos necesarios del DOM utilizando los metodos vistos según el caso (ej: getElement..... querySelector.....)
3. Renderizado Dinámico
Crea una función para recorrer tu array de objetos y, por cada uno, crear un elemento HTML (puedes usar un template string con innerHTML).
Asegúrate de que cada elemento visual refleje las propiedades de tu objeto (ej: el nombre aparezca en un <h3> y el precio en un <p>).
4. Gestión de Eventos
Captura los valores de los inputs, crea un nuevo objeto y agrégalo a tu array mediante botones que "escuchen" el evento click.
Integrar un evento de teclado para plantear un comportamiento (ej. una barra de búsqueda)
5. Estilos y Estados Visuales
Crea un archivo CSS para un estilado basico, el proyecto no puede quedar en blanco y negro o sin un layout claro.
6. Interacción
El proyecto no debe contar mas con prompts, alert ni console.log ya que debe migrarse todo a manejo de DOM.
Se debe continuar con el modelo de simulador planteado, realizando avances significativos
